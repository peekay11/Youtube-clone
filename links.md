# 🎥 YouTube Clone

This is a simple YouTube Clone project designed with a clean and intuitive user interface. It includes skeleton loading animations and theme toggle functionality for a smooth and user-friendly experience.

### 🌟 Features
- **Skeleton Loading Screen**: Displays a placeholder layout while the main content loads.
- **Dark Mode and Light Mode**: Toggle between themes to suit your viewing preference.



### 🚀 Live Demo
Check it out here: [YouTube Clone on Netlify](https://yyyyyoutube-clone.netlify.app/)



  ### 📂 Repository
Find the complete codebase here: [GitHub Repository](https://github.com/peekay11/Youtube-clone)


### 📂 Project Files
- **skeleton.html**: Implements the skeleton loading screen.
- **index.html**: Main page with theme toggle.
- **style.css**: Core styles for the site.
- **skeleton.css**: Styles for the skeleton loading screen.
- **mode.js**: JavaScript for theme toggling and skeleton interactions.
